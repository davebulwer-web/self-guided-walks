    GitHub publishing settings

    Publishing saves the walk and its photos to your repository, and the site updates a minute or two later. The key is stored only in this browser.

    To make a key: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Choose "Only select repositories" and pick this repository. Under Repository permissions, set Contents to "Read and write".
